Necesito rediseñar una landing tipo Linktree para "Futpadel Club".

Objetivo:
Crear una página mobile-first, moderna y premium para centralizar accesos rápidos del club:

- Reservar por WhatsApp
- Agendar hora
- Copiar datos bancarios
- Instagram
- Galería de canchas/club

Estilo visual:

- Deportivo moderno
- Pádel / fútbol / club social
- Limpio, profesional y más actual
- Fondo menos repetitivo, más elegante
- Usar una paleta oscura con acentos verdes, azul petróleo o amarillo deportivo
- Bordes redondeados grandes
- Sombras suaves
- Buen contraste

Cambios principales:

1. Header más potente:
   - Logo o nombre "Futpadel Club"
   - Subtítulo tipo: "Canchas, reservas y comunidad deportiva"
   - Evitar que se vea como una página básica.

2. Galería:
   - Hacerla más grande y protagonista.
   - Usar carrusel visual de alto entre 240px y 320px en mobile.
   - Imágenes con overlay oscuro degradado.
   - Texto encima: "Canchas de Pádel", "Fútbol", "Eventos", etc.
   - Dots más elegantes o mini thumbnails.

3. Botones:
   - Convertirlos en cards/botones grandes.
   - Cada botón con ícono, título y pequeña descripción.
   - Ejemplo:
     - "Reservar por WhatsApp" / "Agenda tu cancha al instante"
     - "Agendar hora" / "Revisa disponibilidad"
     - "Datos bancarios" / "Copia la información de pago"
     - "Instagram" / "Síguenos y mira novedades"
   - El botón principal debe ser WhatsApp, más destacado que el resto.

4. Jerarquía:
   - WhatsApp debe ir primero o como CTA fijo destacado.
   - Luego agendar, datos bancarios e Instagram.

5. UX:
   - Agregar feedback al copiar datos bancarios: toast "Datos copiados correctamente".
   - Botones con hover/tap animation.
   - Diseño cómodo para tocar con el dedo.
   - Separaciones más generosas.

6. Fondo:
   - Reemplazar el patrón repetitivo por:
     - Gradiente oscuro sutil
     - O textura deportiva muy suave
     - O imagen de cancha desenfocada con overlay
   - No debe competir con el contenido.

7. Estructura sugerida:
   - Hero con logo/nombre
   - Galería grande
   - CTA principal de reserva
   - Lista de acciones secundarias
   - Footer pequeño con dirección, horario o Instagram

8. Responsive:
   - Mobile-first.
   - En desktop, centrar contenido con max-width entre 420px y 520px.
   - Mantener sensación de app/card.

Tecnologías:

- React
- Usar componentes reutilizables
- Mantener código limpio
- Usar animaciones sutiles
